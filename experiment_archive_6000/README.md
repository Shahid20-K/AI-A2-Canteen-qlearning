# Archived 6,000-episode experiment snapshot

This folder preserves the completed 6,000-episode result set from the latest uploaded GitHub ZIP before the final 60,000-episode run artifacts were restored.

- `AI_A2_Report_6000_episodes.pdf` is the report generated from the 6,000-episode metrics.
- `results_6000_episodes/` contains the original 6,000-episode metrics, Q-table, training returns, figures, and trace.
- `VALIDATION_NOTES_6000_episodes.md` preserves the earlier interpretation.

These files are archived for audit/history only. The authoritative final report and final evaluation results are in the project root and `results/`.
